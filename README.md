Key Findings

* Analysed 172,765 orders from January 2015 to January 2018.
* Identified an overall late delivery rate of 54.71%.
* Quantified $2.1M in profit at risk associated with delayed orders.
* Identified shipping mode as a major operational bottleneck.
* Developed a Random Forest classification model with 74% accuracy using SMOTE to address class imbalance.

Business Recommendations

* Audit First Class and Second Class shipping performance.
* Implement predictive alerts for high-risk orders.
* Improve payment processing efficiency.
* Develop seasonal capacity planning strategies.
* Continuously monitor and improve delivery performance.
